# Knowledge base

`techniques.json` is a small, hand-curated set of network-relevant MITRE ATT&CK techniques.
The text is written as short paraphrases for this project, not copied from MITRE, and it may be incomplete or simplified.
Always check the real entry at https://attack.mitre.org before relying on it.

MITRE ATT&CK(R) is a registered trademark of The MITRE Corporation.

To use the full matrix instead, run `scripts/ingest_attack.py` (see the README).
